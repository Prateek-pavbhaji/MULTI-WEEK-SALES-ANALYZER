# 📄 Project Statement – Multi-Week Sales Analyzer

## 📝 Problem Statement
Small businesses and individuals often struggle to track weekly sales trends in a structured and consistent way. Manual tracking using notebooks or spreadsheets can be time-consuming and error-prone. There is a need for a simple, user-friendly tool that allows users to input weekly sales data and automatically generate meaningful insights such as weekly totals, performance trends, and highest/lowest daily sales.

---

## 🎯 Scope of the Project
The **Multi-Week Sales Analyzer** focuses on collecting, validating, and analyzing weekly sales input from the user.  
The project covers:
- Recording daily sales for each week  
- Handling multi-week data entry  
- Validating incorrect inputs (e.g., negative values)  
- Calculating weekly totals and overall statistics  
- Displaying results in a clean, organized summary  

**Out of scope:**  
- GUI interface  
- Database storage  
- Graphical analytics or dashboards  
- Integration with external systems (billing apps, POS systems, etc.)

---

## 👥 Target Users
This application is designed for:
- Small business owners who track weekly sales manually  
- Students learning Python basics and data handling  
- Shopkeepers, vendors, or freelancers tracking sales trends  
- Anyone who wants a simple tool to analyze weekly numerical data  

The program is beginner-friendly, requiring no technical setup beyond Python installation.

---

## ⭐ High-Level Features
- 🔹 Input daily sales for Monday to Sunday  
- 🔹 Reject negative values with validation  
- 🔹 Support for an unlimited number of weeks  
- 🔹 Automatic calculation of:
  - Weekly total sales  
  - Grand total sales  
  - Average weekly sales  
  - Best-performing week  
  - Worst-performing week  
  - Highest single-day sale  
  - Lowest single-day sale  
- 🔹 Clear and structured summary output  
- 🔹 Interactive terminal-based user experience
