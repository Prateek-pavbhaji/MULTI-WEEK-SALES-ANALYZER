🧮 Multi-Week Sales Analyzer

## 📘 Overview
The **Multi-Week Sales Analyzer** is a Python-based command-line program designed to help users record and analyze sales data across multiple weeks. By entering daily sales for each week, the program generates a comprehensive summary that highlights weekly totals, averages, best and worst-performing weeks, and the highest/lowest single-day sales. This tool is ideal for small businesses or individuals tracking weekly performance trends.

---

## ⭐ Key Features
- Input daily sales for each day of the week (Mon–Sun)
- Validate against negative sales entries
- Support unlimited weeks of data input
- Automatically calculate:
  - Weekly total sales
  - Grand total sales
  - Average weekly sales
  - Best and worst-performing weeks
  - Highest and lowest single-day sales
- Clear, formatted summary output
- Fully interactive command-line interface

---

## 🛠️ Technologies and Tools Used
- **Python 3.x**
- No external libraries required (pure Python)
- Standard input/output for user interaction

## 🧪 Instructions for Testing the Program

1. Run the script in the terminal:

python sales_analyzer.py


2. Enter daily sales for each day when prompted.

3. Test the following scenarios:

✔ Negative Values

Enter a negative number to verify that the program rejects invalid input.

✔ Multiple Weeks

After completing a week, type "yes" when asked whether to enter another week.

✔ Single Week

Type "no" to generate the final summary after entering one week.

4. Validate the program's output:

 - Weekly totals are calculated correctly

 - Summary accurately identifies:

 - Best-performing week

 - Worst-performing week

 - Highest single-day sale

 - Lowest single-day sale

 - All displayed values match the input

5. Repeat with different inputs to ensure consistent and accurate performance.
